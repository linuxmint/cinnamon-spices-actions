# Changelog

All notable changes to this Action will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.1] - 2026-11-05

### Fixed
- Errors in the debug log are now written on separate lines.

### Changed
- The time list opens taller, so more times are visible at once.
- README rewritten for the Cinnamon Spices, with English screenshots.

## [1.0] - 2026-07-02

### Added
- optimised to be added to Nemo’s official actions

## [1.0] - 2025-08-12
### Added
- Initial release.
- Change the modification date (and time) of one or more selected files via a right-click context menu entry in Nemo.
- Optional backup of modified files (`.bkp` extension).
- Optional debug log of the changes made.
- Translations: English, Italian, German, French, Spanish, Portuguese.
